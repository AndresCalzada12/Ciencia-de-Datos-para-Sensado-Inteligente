# 🧪 Ciencia de Datos y Sensores Inteligentes / Data Science and Smart Sensors

Este repositorio reúne un conjunto de prácticas y un proyecto final orientados al análisis de señales provenientes de sensores inteligentes, aplicando fundamentos de ciencia de datos y aprendizaje automático. A través de diferentes dominios —audio, imagen, movimiento e información fisiológica— se desarrollan técnicas de adquisición, procesamiento, extracción de características y modelado de datos.

This repository collects a series of practical exercises and a final project focused on signal analysis from smart sensors, applying data science and machine learning principles. It covers various domains —audio, image, motion, and physiological signals— and includes techniques for acquisition, preprocessing, feature extraction, and modeling.

---

## 📂 Estructura del repositorio / Repository Structure

### `audio_processing/`
- 🎧 Processing and classification of audio signals using spectral features and ML models.

### `image_processing/`
- 🖼️ Analysis of raw images and landmark-based classification from video data.

### `inertial_analysis/`
- 🏃 Detection of movement patterns and classification of exercise quality with IMU data.

### `physiological_signals/`
- ❤️ HRV signal filtering and time-domain analysis from wearable sensors.

### `nerviosismo_hrv_project/`
- 🧠 Final project detecting nervousness during cognitive stress using HRV signal analysis with validation via self-report surveys.
