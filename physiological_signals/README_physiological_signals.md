## ❤️ Heart Rate Variability (HRV) Signal Analysis / Análisis de Señales de Variabilidad de Frecuencia Cardíaca

This module explores the processing and analysis of heart rate variability (HRV) signals, derived from ECG data collected using wearable devices and exported from the Elite HRV app. The workflow focuses on noise reduction, signal visualization, and interpretation in the time domain.

Este módulo explora el procesamiento y análisis de señales de variabilidad de la frecuencia cardíaca (HRV), derivadas de datos ECG recolectados con sensores portátiles y exportados desde la aplicación Elite HRV. El flujo de trabajo se enfoca en la reducción de ruido, visualización de señales e interpretación en el dominio del tiempo.

---

### 📘 `heart_rate_variability_analysis.ipynb`

#### 🇬🇧 English  
This notebook covers:

- Importing ECG-based HRV data from `.txt` files.
- Visualizing raw signals using `matplotlib`.
- Filtering noisy HRV signals.
- Time-domain signal interpretation using `HeartPy`.

> 💓 The objective is to prepare clean HRV signals for further clinical or ML-based analysis.

#### 🇪🇸 Español  
Este notebook cubre:

- Importación de señales HRV basadas en ECG desde archivos `.txt`.
- Visualización de señales crudas con `matplotlib`.
- Filtrado de señales HRV con ruido.
- Interpretación de señales en el dominio del tiempo usando `HeartPy`.

> 💓 El objetivo es preparar señales HRV limpias para análisis clínicos o con aprendizaje automático.
